# Template Ghi Nhận Lịch Sử Thay Đổi (Changelog Template)

Sử dụng cấu trúc này khi ghi nhận thay đổi vào `CHANGELOG_AI.md`:

```markdown
## [YYYY-MM-DD] - <Tên Tính Năng Hoặc Tác Vụ Cụ Thể>
- **Mục đích**:
  - Giải thích nguyên nhân hoặc yêu cầu dẫn đến thay đổi này.
- **Các file bị ảnh hưởng (Affected Files)**:
  - `path/to/file1.ext`: Thay đổi gì.
  - `path/to/file2.ext`: Thay đổi gì.
- **Chi tiết kỹ thuật**:
  - Bổ sung/sửa đổi hàm: `funcA()`, `funcB()`.
  - Thay đổi cấu trúc dữ liệu / tham số: `param1`, `field2`.
  - Điều chỉnh giao diện / CSS / HTML (nếu có).
- **Kết quả kiểm thử (Verification)**:
  - Unit test / Integration test: Kết quả chạy test (VD: Pass 14/14).
  - Kiểm tra giao diện / API: Đạt yêu cầu thực tế.
```
